# Power of a Point and Centripetal Acceleration

Bilingual manuscript on the power-of-a-point theorem and its application to centripetal acceleration.

- `pt-br/`: Brazilian Portuguese adaptation using the native LaTeX `article` class.
- `en/`: original English-language manuscript (`elsarticle` preprint variant).
